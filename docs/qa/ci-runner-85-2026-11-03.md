# CI-Runner-Kompatibilität (#85), 03.11.2026

## Befund und kleinste Änderung

`ubuntu-latest` wählt inzwischen Ubuntu 26.04 x64. Das unveränderte Lockfile
enthält Playwright 1.58.2, dessen Browser-Registry Ubuntu 24.04 x64 unterstützt,
Ubuntu 26.04 jedoch nicht. Der bestehende CI-Job wird auf `ubuntu-24.04` gepinnt.
Kein Paket-/Lockfile-Upgrade und kein ausgelassener Schritt; keine Produktänderung.

## Reproduzierender roter Nachweis

[CI 41602038330](https://github.com/ostheimer/cloudlearn/actions/runs/41602038330)
am Head `ea70d7156d8c7b7faa8edb62f60b0c654e962362` scheitert bei
`pnpm exec playwright install --with-deps chromium` mit:
`Playwright does not support chromium on ubuntu26.04-x64`.
Vorherige SQL-/Test-/Restore-/Build-Schritte sind grün. Der Fehler betrifft die
Runner-/Browser-Kompatibilität unabhängig von der dort geprüften Produktänderung.

Dieser tatsächliche CI-Fehler ist die Reproduktion des Infrastrukturfehlers.
Die Gegenprobe ist derselbe vollständige CI-Job mit derselben Browserinstallation
und anschließendem Smoke-Test auf Ubuntu 24.04. Ein isolierter Unit-Test des
Runner-Strings würde die echte Installation nicht prüfen. Der grüne Run wird im
PR verlinkt; ein reiner Dokumentationsnachtrag benötigt keinen künstlichen Rot-Test.
